## 🚀 التثبيت بنقرة واحدة

### 🪟 ويندوز (الأسهل والأقوى)
1. حمّل المشروع ZIP وفك الضغط
2. **كليك يمين** على `FF-TurboNet-Windows.bat` → **Run as administrator**
3. اختر `[1]` — التطبيق الكامل (تعطيل Nagle + TCP + خلفية)
4. **أعد تشغيل الجهاز** لتفعيل تعطيل Nagle بالكامل
5. استمتع ببينق أقل وثبات أعلى 🎮

> للاسترجاع: شغّل نفس الملف واختر `[6] Undo` — يعيد كل شيء كما كان.

### 📱 أندرويد / تيرمكس
1. ثبّت [Termux](https://f-droid.org/packages/com.termux/) من F-Droid (نسخة F-Droid تعمل بدون مشاكل)
2. انسخ مجلد `ff-turbonet` إلى الهاتف وافتح تيرمكس:
```bash
cd /sdcard/ff-turbonet        # أو /storage/emulated/0/ff-turbonet
bash ff-turbonet-termux.sh
```
3. السكريبت يثبّت المتطلبات تلقائيًا — اختر من القائمة:
   - `[1]` فحص البينق
   - `[2]` التحسينات (يحتاج روت — أو استخدم `[4]` للنصائح اليدوية بدون روت)

### 🐧 لينكس (لاعبو المحاكي/PC)
```bash
sudo python3 ff_turbonet.py boost
```

## 🎯 ماذا تفعل كل أداة؟

### 1️⃣ فحص البينق الشامل (`ping`)
يقيس TCP Ping الحقيقي لسيرفرات فري فاير الرسمية (بنغلاديش/سنغافورة/إندونيسيا/الهند/الشرق الأوسط) ويحدد **أفضل سيرفر لاتصالك** مع تقييم شبكتك من 5. هكذا تعرف أين تتصل اللعبة فعلًا ولماذا يحدث اللاق.

### 2️⃣ تقنين DNS (`dns`)
يستعلم يدويًا عن `ff.garena.com` عبر 6 مزودين DNS (Cloudflare/Google/Quad9/OpenDNS) ويقيس زمن الاستجابة الفعلي، ثم يعيّن الأسرع لك. تأخير DNS = انتظار طويل عند كل دخول للعبة وتحديث بيانات.

### 3️⃣ تحسينات TCP/النظام (`tune`)
19 تحسينًا محترفًا عبر sysctl: خوارزمية **BBR** من جوجل (إن توفرت)، TCP Fast Open، اكتشاف MTU، SACK، F-RTO، نوافذ أكبر، إبقاء حي كل 60 ثانية بدل ساعتين، مخازن UDP ضخمة (فري فاير = UDP). كلها إعدادات نظامك الخاص.

### 4️⃣ وضع اللعب (`game`)
يوقف البرامج الخلفية التي تسرق الشبكة (OneDrive/Dropbox/محدّثات/ديسكورد...) ويقيس الاتصالات النشطة. أي برنامج يرفع بيانات أثناء الماتش = لاق.

### 5️⃣ المراقبة المباشرة (`monitor`)
تشغّلها وأنت تلعب — ترصد البينق والـjitter والفشل لحظيًا وتعطيك تشخيصًا في النهاية (هل المشكلة من مزودك؟ من الواي فاي؟ من السيرفر؟).

### 6️⃣ Undo (`undo`)
استرجاع كامل لكل الإعدادات الأصلية — نسخة احتياطية قبل كل تعديل، وملفات ريجستري في ويندوز.

## ❓ لماذا هذا قانوني ولن يُحظر حسابي؟

قواعد فري فاير (Garena Fair Play Policy) تحظر **تعديل العميل أو اللعب مع برامج غش أو التلاعب بالحزم**. هذه الأداة:

- تعمل على **نظام التشغيل** (TCP/DNS/خدمات) — لا على اللعبة
- لا ترسل أي شيء للسيرفر — فقط ping عادي مثل أي متصفح
- لا تفتح ولا تكتب ولا تقرأ أي ملف من ملفات فري فاير
- كل تعديل معه **نسخة احتياطية وUndo** — أنت المتحكم الكامل

تشبيه بسيط: إذا كانت اللعبة سيارة، فالأدوات الأخرى تعبث بالمحرك (حظر مؤكد)، بينما FF-TurboNet **ترصف لك طريقًا أفضل** (حقك الكامل).

## ⚡ نصائح ذهبية (الأداة + هذه النصائح = أقصى أداء)

1. **سلك Ethernet > واي فاي 5GHz > واي فاي 2.4GHz > بيانات الجوال** — دائمًا بهذا الترتيب
2. لا تلعب أثناء شحن الهاتف (سخونة = خفض أداء المعالج = لاق مرئي)
3. أغلق تحديثات Google Play قبل الماتشات: إعدادات Play → تنزيل تلقائي → بدل الشبكة
4. اختر السيرفر الأقرب لبلدك من داخل اللعبة (وضع البقاء → اختيار المنطقة)
5. في الأعدادات → رفع معدل الإطارات من 30 إلى 60/90 — اللاق المرئي نصفه إطارات
6. أعد تشغيل الراوتر مرة أسبوعيًا — يخفض تكدس الجلسات
7. لا تضع الراوتر بجوار ميكروويف/هاتف لاسلكي (تداخل 2.4GHz)
